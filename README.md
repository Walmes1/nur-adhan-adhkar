# 🕌 Nûr — Adhan & Adhkar

Application gratuite : Adhan automatique aux 5 prières (selon votre position), Adhkar du matin et du soir, Douaa, Roqya et Coran. Fonctionne hors ligne pour l'Adhan et les audios inclus.
Free app: automatic Adhan for the 5 prayers, morning/evening Adhkar, Douaa, Roqya and Quran. Works offline for Adhan and bundled audio.
